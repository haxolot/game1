# Documentation et Game Design - Action-RPG 2D

Ce depot rassemble la documentation complete, la vision de conception, le lore et la feuille de route du projet de jeu video Action-RPG 2D en pixel art.

## Presentation Rapide
* Genre : Action-RPG Aventure 2D en Pixel Art
* Style de combat : Dynamique, exigeant, epique, elements Souls-like
* Narration : Focalisation majeure sur le Lore et la narration environnementale
* Moteur cible : Unity (URP 2D, New Input System)
